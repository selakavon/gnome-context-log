# Context Log (GNOME Shell extension)

Top-panel widget recording what you are working on.

- Click it, type a one-line description, press Enter: recorded with the current time. The **Add as todo** checkbox next to the field (on by default) also puts the task on the to-do list, unless a to-do with the same text already exists.
- The newest timeline row has a **stop** button that ends the running task without starting a new one (lunch, end of day). The panel label clears, the task's time spent ends there, and the timeline shows a *Stopped* row.
- **Timeline** lists each record: date-time, description, time spent (until the next record). Double-click a row to work on that task again.
- **To-do** is a checklist with two tabs. **Open** lists what is still to do, sorted by priority first, then by time added. **Done** lists finished to-dos, most recently finished first, each with the date and time it was checked off. Type and press Enter to add (the list switches to Open). Double-click a to-do's text to set it as the task you're working on now (it gets recorded in the log and highlighted). Click its checkbox to toggle done, which moves it to the other tab; the X removes it. The pencil on an open to-do changes its title: edit the text and press Enter (Escape closes the menu and discards the edit). The task's timeline rows, and the panel label if it is the running task, take the new title too. Each item has a priority chip (H/M/L); new to-dos start at Medium, and clicking the chip cycles Medium -> High -> Low. Stored in `~/.local/share/context-log/todos.json` as `{text, done, priority, added, doneAt?}`; `doneAt` is set when the item is checked off and cleared when it is reopened. To-dos finished before `doneAt` existed keep working: they have no done time, show no date, and are ordered by the time they were added.

Log: `~/.local/share/context-log/entries.jsonl`, one JSON object per line: `{"time":…,"description":…}`, `{"time":…,"stop":true}` for a stop, or `{"time":…,"rename":{"from":…,"to":…}}` for a changed title. A rename applies to every record above it described as `from`; the file is only ever appended to, so the original lines stay as written.
Install / update: `./install.sh` (copies into `~/.local/share/gnome-shell/extensions/` and restarts the shell on X11).
